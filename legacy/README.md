# Legacy experiments

These files are kept for reference and are not part of the supported application path.

- `diarize_pyannote.py` is the original pyannote diarization experiment. The current API uses the shared NeMo runtime in `diarization.py`.

- `transcribe_multi.py` is the older multitalker Parakeet experiment with its own model assumptions. It is retained for reference, not used by the API.
